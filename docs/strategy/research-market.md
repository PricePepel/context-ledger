## Gaps Context Ledger could own

1. **Auditable handoff.** Most competitors either summarize with an LLM (claude-mem, Supermemory, Pieces) or dump raw history (SpecStory). Line-cited, typed decisions, blockers and ready actions are a verifiable middle ground, and they matter to regulated or security-minded teams.
2. **Local-first and self-hostable for teams.** Nessie's on-prem tier is custom-priced. Entire needs its forge. A self-hosted team ledger with no cloud dependency, permissively licensed (not AGPL), is underserved.
3. **Neutral cross-vendor handoff contract.** Cursor dropped native memory, and Windsurf and Claude auto-memory are tool-local. A small open "handoff packet" format that maps to Agent Trace and to Git notes could become an interoperability standard and wedge.
4. **Decisions linked to PRs and commits, without switching forges.** Bring Entire-style "why" context to plain GitHub through a GitHub App or CI check that attaches the semantic graph to the PR. Entire requires moving to its platform; this would not.
5. **Intent observability.** Observability tools trace tokens and cost. Nobody reports which decisions were made, which are reversed, or which blockers are stale across agents. A manager-facing view of decisions and blockers is open.

## Strongest reason a buyer would NOT need it

Platform absorption. Anthropic already ships auto memory and reportedly shareable session pages. Codex has resume plus a memories setting. Entire has $60M to make Git-native session memory the default, and Nessie already covers Claude Code and Codex with an MCP server and CLI. For a single-vendor shop (everyone on Claude Code), native features plus CLAUDE.md are "good enough." That leaves Context Ledger's defensible value in **cross-vendor teams that need auditability or self-hosting**, which is a narrower market. Cursor removing Memories suggests native memory is hard to do well, but that alone is not a moat.
